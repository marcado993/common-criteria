Guía de Common Criteria en español · Parte 2: requisitos funcionales de seguridad

Clases, familias y componentes de ISO/IEC 15408-2 (CC:2022, revisión 1), con dependencias. Funciona sin conexión.

Glosario rápido
Common Criteria (CC)
Norma internacional para especificar y evaluar la seguridad de productos de TI.
SFR
Requisito funcional de seguridad: lo que el sistema debe hacer en seguridad. Son los componentes de esta guía (por ejemplo, FAU_GEN.1).
TOE
Objetivo de evaluación: el producto o sistema que se evalúa (en tu caso, el ERP).
TSF
Funciones de seguridad del TOE: las partes del sistema que hacen cumplir la seguridad.
SFP
Política de funciones de seguridad: la regla que el sistema aplica (por ejemplo, una política de control de acceso).
Dependencias
Si pides un componente, normalmente debes pedir también los que necesita para funcionar. Ejemplo: FAU_GEN.1 depende de FPT_STM.1 (sellos de tiempo).
Cómo leer un código
FAU_GEN.1 = clase FAU (auditoría) · familia GEN (generación) · componente 1 (nivel de exigencia; cada número suele ser más exigente que el anterior).
